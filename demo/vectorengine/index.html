Cuis VectorEngine — faithful JS port (fill + stroke)

Anti-aliased vector shapes rasterized by a method-for-method JavaScript port of Cuis' VectorEnginePlugin (Juan Vuletich), running natively in the browser — no Squeak VM. Geometry → transform → line/quadratic/cubic flattening → 3-channel sub-pixel coverage → blendFillOnly / blendStrokeAndFill / blendStrokeOnly. Bands: filled · fill+stroke · stars · stroke-only spirals.
